# 🎓 Student Management System

> 📌 A simple Java-based application to manage student records efficiently.

## 🎯 About the Project

The **Student Management System** is a console-based Java application developed to manage student information. It allows users to add, view, search, update, and delete student records.

This project demonstrates my understanding of **Java programming, Object-Oriented Programming, ArrayList, classes, objects, and CRUD operations**.

## ✨ Features

* ➕ Add Student
* 👀 View Students
* 🔍 Search Student
* ✏️ Update Student
* 🗑️ Delete Student
* 🚪 Exit the Application
